# Curling Strategy Tool - Changelog

## 2026-09-18

### Specification v1.0

- プロジェクト仕様書を正式版 v1.0 として整理
- 4人制とMixed Doublesを共通設計で扱う方針を明確化
- 盤面記録、投球状態継承、ショット評価、AI分析の方向性を確定
- ゲーム形式ごとの差分を「設定差分」として扱う設計に整理
- MVPスコープと将来拡張の境界を明文化

## 2026-09-17

### Project initialization

- カーリング戦略記録・分析アプリの開発開始
- React + TypeScript + Viteを採用
- Windows 10環境を構築
- Node.js 24.21.0を導入
- VS Codeを導入・日本語化
- Gitを導入
- 初回Gitコミットを作成

### Match format

- 4人制に対応
- 4人制は10エンドを基本とする
- 4人制はエキストラエンドに対応
- Mixed Doublesに対応
- MDは8エンドを基本とする
- MDはエキストラエンドに対応

### Recording

- 1投ごとの盤面状態を保存する方針を決定
- 投球後の盤面をユーザーがドラッグで調整する方式を採用
- 新しいストーンは投球後に自動追加する
- シート外へ出したストーンはアウト石として管理する
- Undo / Redoを採用
- ショット種類を記録
- ショット実行評価を0〜5で記録
- 戦略評価とショット実行評価を分離

### Board

- ホグライン〜バックライン、サイドライン内を表示
- ハウス・フリーガードゾーンの尺度を正確にする方針
- ラインを細身で表示
- ストーンは規格平均サイズを基準
- ハウスを薄く着色
- ストーン位置を座標データとして保存する方針

### Score

- 得点盤は盤面記録から独立
- エンド終了時に得点をユーザーが入力
- 得点結果を利用して次エンドのハンマー・試合進行を管理

### Future output

- 各投球のハウス状態を並べた紙媒体用一覧を将来実装
- ショット種類・評価を盤面と併記
- 4人制16投、MD10投に対応
- AI分析用データとしても利用できる構造を目指す
